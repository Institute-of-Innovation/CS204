# To-Do List

This project is a simple To-Do List application built using Python. It allows users to manage their tasks by adding, viewing, marking as completed, and deleting tasks.


## Features
- Add new tasks to the list.
- View all tasks in a structured format.
- Mark tasks as completed.
- Delete tasks when no longer needed.
- Simple and user-friendly command-line interface.
- Prerequisites
- Python installed on your system (Python 3.x recommended).
- A text editor or IDE (VS Code, PyCharm, Notepad++, etc.).

## Steps to Install and Run
1. **Clone the Repository** (if applicable):
git clone https://github.com/username/todo-list.git

2. **Navigate to the Project Folder:**
cd todo-list

3. **Run the Python Script:**
python todo_list.py


## File Structure
/L0-To-Do-List(Basic)

## Usage and Customization
- Run the script in a terminal or command prompt.
- Follow the menu options to add, view, complete, or delete tasks.
- Modify todo_list.py to add more features like task deadlines or priorities.
