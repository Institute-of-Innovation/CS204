## Simple Calculator

This project is a basic **Simple Calculator** built using **Python.** It allows users to perform fundamental arithmetic operations like addition, subtraction, multiplication, division, and modulus calculations.

## Features
- Performs basic arithmetic operations (addition, subtraction, multiplication, division, modulus).
- Continuously allows calculations until the user decides to exit.
- Handles invalid inputs and prevents division by zero errors.
- Displays meaningful error messages when incorrect inputs are entered.

## Prerequisites

- Python installed on your system (Python 3.x recommended).
- A text editor or IDE (VS Code, PyCharm, Notepad++, etc.).
