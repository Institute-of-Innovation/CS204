# Random Password Generator

TThe Guess the Number Game is a simple Python-based number guessing game. The program randomly selects a number between any random range and the player has a limited number of attempts to guess it correctly.

In this game, python fundamentals like if, elif, while loop,user input are used.

## Features
1. Randomly selects a secret number range.
2. Provides feedback on whether the guess is too high or too low.
3. Prevents duplicate guesses.
4. Input validation to ensure only valid numbers are entered


## Prerequisites
- Python (3.x) 
- A text editor (VS Code, Sublime Text, Notepad++, etc.).
