# Guess the Word

This project is a simple **Guess the Word** game built using **Python**. The game randomly selects a word and provides a hint to help the player guess it. The player has a limited number of attempts to guess the word correctly.

## Features
- Randomly selects a word from a predefined list.
- Provides a hint for each word.
- Tracks guessed letters and displays progress.
- Allows multiple attempts to guess the word.
- Displays game over message if the player runs out of attempts.

## Prerequisites
- Python installed on your system (Python 3.x recommended).
- A text editor or IDE (VS Code, PyCharm, Notepad++, etc.).
