# Library Management System

## Overview
This is a simple Python-based Library Management System that allows users to add books, view available books, borrow books, and return books.

## Features
- Add new books with a unique ID.
- View a list of available books.
- Borrow books by entering their ID.
- Return borrowed books.
- User-friendly menu-driven interface.

## How to Use
1. Run the script in a Python environment.
2. Choose from the menu options:
   - Add a book by entering its title and author.
   - View available books.
   - Borrow a book by entering its unique ID.
   - Return a borrowed book by entering its unique ID.
   - Exit the system.
3. Follow the prompts to interact with the system.

## Example Usage
```
Library Management Menu
1. Add Book
2. View Books
3. Borrow Book
4. Return Book
5. Exit
Enter your choice: 1
Enter book title: Python Basics
Enter book author: John Doe
Book 'Python Basics' added with ID 1234.
```

## Requirements
- Python 3.x

## Installation
1. Clone the repository or download the script.
2. Run the script using:
   ```
   python library_management.py
   ```
