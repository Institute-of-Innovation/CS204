# Guess The Number Game 

This simple project is made in python. It allows users to gusess number in given attempts.
The Random Password Generator is a Python script that creates secure, randomized passwords.
It allows users to specify the desired length and complexity, ensuring strong security for online accounts.

## Features
1. Randomly selects a secret number range.
2. Provides feedback on whether the guess is too high or too low.
3. Prevents duplicate guesses.
4. Input validation to ensure only valid numbers are entered.
